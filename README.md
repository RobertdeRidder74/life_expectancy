Life expectancy Project

The course HarvardX PH125.9x: Data Science Capstone is the ninth and final 
component of the Data Science Professional Certificate program. Within this course, 
students are required to complete two projects that together determine the final grade.
This report describes the second project, in which students are free to select 
their own research topic. For this study, the chosen topic is an analysis of 
socio-economic factors that may influence life expectancy at birth.

Environment

Developed in RStudio using R version 4.5.1.

Programming language: R

Files:

-markdown_life_expectency.Rmd

  The R Markdown file used to generate the final report. It contains explanatory text and code chunks.

-life_expactancy_r_script.R

  The R script that performs all computations, data processing, model training, and evaluation.

-markdown_life_expectency.pdf

  The final report generated from the R Markdown file.

Notes

Running the script and knitting the R Markdown file may take several minutes, depending on your hardware.
